# Sistema de Agendamento Online · Clínica

Sistema completo de agendamento online para clínicas e consultórios.

## 🔗 Demo ao vivo
https://vita-agendamento.vercel.app/

## ✦ Destaques
- Fluxo de agendamento em 4 etapas com navegação livre
- Seleção de especialista com avaliações e disponibilidade
- Seleção de tipo de consulta com preço e duração
- Calendário real navegável por mês
- Horários com slots ocupados e disponíveis
- Resumo lateral atualizado em tempo real
- Tela de confirmação com código único gerado
- Validação de formulário em tempo real
- 100% responsivo para mobile e desktop

## 🛠 Tecnologias
HTML5 · CSS3 · JavaScript Vanilla · Google Fonts
